# GABBRO

The manifest has a path that escapes the install directory, appears more than once, or conflicts with another entry. The launcher stopped before it wrote that path.

## Try this

1. Choose **Retry** once. The publisher can replace a temporary manifest.
2. Check if the official client is updating or in maintenance.
3. If the code returns, choose **Report Problem**.

> [!CAUTION]
> Do not bypass this check or recreate the rejected path by hand. Repair uses the same manifest and cannot make an unsafe manifest valid.

## Report this problem

Report the code, operation, and region.

If the official client also rejects the release, see [publisher support routing](../README.md#publisher-support-routing).
