# CRUX

The Wine or game process ended before launch finished, or exited abnormally while the game ran.

## Try this

1. Close overlays and tools that modify game processes, then choose **Retry**.
2. If a game file is missing or corrupt, choose **Repair** and confirm the full verification.
3. If the code returns, see [The game will not start](../troubleshooting.md#the-game-will-not-start).

> [!IMPORTANT]
> A normal exit does not produce CRUX. The code means an abnormal or early exit.

## Report this problem

Report the code, operation, region, whether a window appeared, and what happened before the exit.
