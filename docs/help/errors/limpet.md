# LIMPET

The bundled Intel Wine runtime cannot start: Rosetta is unavailable or failed to install, or Legacy Game Test Mode disabled translation on a macOS 27 beta.

## Try this

1. If offered, choose **Install Rosetta…**, confirm the macOS prompt, and wait.
2. Choose **Retry** or **Check Again**.
3. On a macOS 27 beta, turn off Legacy Game Test Mode. See [macOS compatibility](../runtime-compatibility.md#legacy-game-test-mode-on-macos-27-beta). Restart the Mac and check again.
4. Install pending macOS updates.

> [!IMPORTANT]
> Rosetta is Apple system software. Arknights Client does not bundle or modify it. Repair cannot fix it.

## Report this problem

Report the code, macOS version, whether the launcher offered an installation, and whether other Intel apps run.
