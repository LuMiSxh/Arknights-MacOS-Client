# LIMPET

The bundled Intel Wine runtime cannot start because Rosetta is missing, its installation failed, or Legacy Game Test Mode disabled the required translation path.

## Try this

1. If the launcher offers **Install Rosetta…**, confirm the macOS system prompt and wait for it to finish.
2. Choose **Retry** or **Check Again** after installation.
3. If Legacy Game Test Mode is enabled, disable it as described in [Runtime compatibility](../runtime-compatibility.md#macos-27-legacy-game-test-mode), restart the Mac, and check again.
4. Install pending macOS updates.

> [!IMPORTANT]
> Rosetta is Apple system software. Arknights Client does not bundle or modify it.

Repair only checks game files and cannot fix Rosetta.

## Report this problem

Report the code, macOS version, whether installation was offered, and whether Apple Silicon translation still works for other Intel apps.
