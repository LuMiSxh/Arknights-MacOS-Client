# NARWHAL

Wine started the game process, but Arknights showed no visible window within 90 seconds.

## Try this

1. Wait until other heavy downloads or first-run macOS work finish.
2. Choose **Retry** once. Later starts are often faster.
3. If the launcher reports missing or corrupt files, choose **Repair** and confirm the full verification.

> [!NOTE]
> If the game window is visible and only the sign-in or Notices window is blank, see [Sign-in or Notices stay blank](../troubleshooting.md#sign-in-or-notices-stay-blank).

## Report this problem

Report the code, region, whether this was the first launch after an update, and whether a second attempt differed.
