# VIRGA

The launcher could not get valid configuration or service data for the selected region. This includes the first configuration refresh and a game-update check that you start.

## Try this

1. Check that the Mac can open ordinary websites.
2. If the game service is in maintenance, wait, then choose **Retry**.
3. Briefly turn off any VPN, proxy, DNS filter, or network security tool, then retry.
4. Try another network.

> [!NOTE]
> Retry repeats the operation for the same region. It deletes no installation or partial download.

## Report this problem

Report the code, region, and whether another network behaved differently. Do not post response bodies, account details, or private URLs.

If the official service is also down, wait for recovery. See [publisher support routing](../README.md#publisher-support-routing).
