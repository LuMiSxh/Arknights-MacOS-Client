# SCREE

The selected install volume has less free space than the operation needs.

## Try this

1. Free the space the launcher shows, plus extra for updates.
2. Empty the Trash if it holds a previous installation.
3. If needed, choose another local volume in **Settings → Installation**.
4. After the free-space value changes, choose **Retry**.

> [!TIP]
> Retry checks capacity again. It keeps valid downloads.

Repair can need almost the full installation size.

## Report this problem

Report only if Finder shows enough free space and the code remains. Include the code, operation, region, volume format, and the free-space values of Finder and the launcher.
