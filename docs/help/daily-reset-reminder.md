# Daily reset reminder

The daily reset happens at 04:00 server time. The launcher can show a macOS notification before it. The reminder is off by default.

## Turn it on

1. Open **Settings → Integration**.
2. Choose a time under **Daily reset reminder**: **At reset**, **15 minutes before**, **30 minutes before**, **1 hour before**, or **2 hours before**.
3. Allow notifications when macOS asks.
4. Open **Servers** and choose the servers to remind you about.

Setup also asks this question. The first reminder uses the server you selected on the home screen.

## How it works

- The launcher asks macOS to show each reminder for the next 7 days.
- macOS shows the reminders even when the launcher is closed.
- The launcher refreshes the reminders when it opens, when your Mac wakes, and when the time zone or clock changes.
- Only installed servers are listed.
- Server time does not change with daylight saving time. Your local time of the reset can change.

Open the launcher at least once a week to keep the reminders going.

## Notifications are off

If macOS blocks notifications, **Settings → Integration** shows **Notifications are off for Arknights Client.** The reminder turns off.

1. Choose **Open System Settings**.
2. Turn on **Allow Notifications** for Arknights Client.
3. Return to the launcher and choose a time again.

The launcher sends no data anywhere. macOS schedules and shows the notifications on your Mac.
